# 🌐 Working With AI Course For Web Developers
## Kế hoạch chi tiết khoá học

> **Đối tượng**: Web Developer — Frontend, Backend, Full-stack, từ junior đến senior.
> **Mục tiêu**: Sử dụng AI như một pair programmer thông minh — từ coding đến deploy, từ debugging đến architecture design.

---

## 📌 Triết lý khoá học

| Nguyên tắc | Áp dụng cho Web Developer |
|---|---|
| **"Kiến trúc sư vs Thợ xây"** | Dev là người thiết kế hệ thống, AI là người viết code nhanh |
| **Workflow > Syntax** | Tập trung vào development workflow, không chỉ code snippets |
| **Context là chìa khoá** | PROJECT_CONTEXT.md, tech stack, API docs, coding standards |
| **Dự án thực tế** | Xây WebDevHub — full-stack web app với AI assistance |

### Triết lý cốt lõi:

> *"AI không thay thế web developer — bạn vẫn là người kiến trúc hệ thống, đưa ra quyết định kỹ thuật, và review code. AI giúp bạn code nhanh hơn, debug nhanh hơn, và ship sản phẩm nhanh hơn."*

## 📚 Curriculum — 12 Sections, ~75 Lessons

### Section 1: Welcome & AI for Web Developers (6 lessons)
Giới thiệu, công cụ AI, setup, dự án WebDevHub.

### Section 2: Prompt Engineering for Web Dev (7 lessons)
Prompt cho code generation, debugging, API design, component creation.

### Section 3: Context Engineering for Web Projects (6 lessons)
PROJECT_CONTEXT.md, tech stack docs, API specs, coding standards.

### Section 4: AI for Frontend Development (8 lessons)
React/Vue components, styling, responsive design, state management, forms.

### Section 5: AI for Backend Development (7 lessons)
API design, database schema, authentication, middleware, error handling.

### Section 6: AI for Full-Stack Integration (7 lessons)
Connect frontend + backend, data fetching, real-time features, testing.

### Section 7: AI for DevOps & Deployment (6 lessons)
CI/CD, Docker, deployment, monitoring, performance optimization.

### Section 8: Skills & Agents for Web Dev (6 lessons)
Skills: component generation, API scaffolding, test creation. Agents: code reviewer, security scanner.

### Section 9: AI for Debugging & Problem Solving (6 lessons)
Systematic debugging, error analysis, performance profiling, security audit.

### Section 10: AI for Learning & Career (5 lessons)
Learn new frameworks, interview prep, portfolio building, freelancing.

### Section 11: Capstone — Full-Stack Web App (6 lessons)
Build complete web app: planning → frontend → backend → deploy → demo.

### Section 12: Future & Course Wrap-Up (4 lessons)
AI trends in web dev, customize workflow, tổng kết.

## 🔄 Web Developer AI Workflow

```
┌─────────────────────────────────────────────────────────────┐
│              WEB DEVELOPER AI-ASSISTED WORKFLOW              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. PLAN       → Break down features, create tasks          │
│  2. DESIGN     → Architecture, API design, DB schema        │
│  3. CODE       → AI generates code, you review              │
│  4. TEST       → AI writes tests, you verify                │
│  5. DEBUG      → AI helps find and fix bugs                 │
│  6. REVIEW     → AI reviews code quality & security         │
│  7. DEPLOY     → CI/CD, monitoring                          │
│  8. ITERATE    → Refine based on feedback                   │
│  9. DOCUMENT   → AI generates docs                          │
│  10. SHIP      → Release to production                      │
│                                                             │
│  ⚠️ REVIEW là BẮT BUỘC — không merge code AI chưa review   │
└─────────────────────────────────────────────────────────────┘
```
