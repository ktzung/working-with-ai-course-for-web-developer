# Ôn tập khóa học & Bảng gian lận

## Xin chúc mừng!

Bạn đã hoàn thành toàn bộ khóa học "Làm việc với AI cho lập trình viên web"! Hãy ôn lại mọi thứ đã học và tạo bảng gian lận toàn diện bạn có thể tham khảo bất cứ lúc nào.

## Tóm tắt khóa học

### Phần 1: Cơ bản AI
- Hiểu AI hoạt động thế nào cho lập trình viên
- Thiết lập môi trường phát triển AI
- Kỹ thuật prompt engineering hiệu quả
- Chọn công cụ AI phù hợp cho mỗi task

### Phần 2: AI cho tạo code
- Tạo code mẫu với AI
- Tạo components và hàm
- Xây APIs và schemas database
- Viết code sạch, dễ bảo trì với AI

### Phần 3: AI cho phát triển frontend
- Tạo component UI
- Thiết kế responsive với AI
- Mẫu quản lý state
- Thiết kế animation và tương tác

### Phần 4: AI cho phát triển backend
- Thiết kế và triển khai API
- Tối ưu database
- Xác thực và bảo mật
- Render phía server

### Phần 5: AI cho testing
- Tạo unit tests
- Integration và E2E testing
- Phát triển hướng dẫn test với AI
- Độ phủ code và chất lượng

### Phần 6: AI cho DevOps
- Docker và containerization
- Thiết lập pipeline CI/CD
- Triển khai cloud
- Giám sát và logging

### Phần 7: AI cho cộng tác
- Review code với AI
- Tạo tài liệu
- Tối ưu quy trình nhóm
- Chia sẻ kiến thức

### Phần 8: AI cho hiệu suất
- Tối ưu frontend
- Tinh chỉnh hiệu suất backend
- Tối ưu truy vấn database
- Chiến lược caching

### Phần 9: AI cho gỡ lỗi
- Quy trình gỡ lỗi có hệ thống
- Phân tích lỗi và stack traces
- Phân tích hiệu suất
- Kiểm tra bảo mật

### Phần 10: AI cho phát triển sự nghiệp
- Học framework mới
- Chuẩn bị phỏng vấn
- Xây dựng portfolio
- Freelance và mã nguồn mở

### Phần 11: Dự án Capstone
- Phát triển ứng dụng web full-stack
- Lập kế hoạch, xây dựng, test và triển khai
- Kinh nghiệm dự án thực tế

### Phần 12: Tương lai & Tổng kết
- Xu hướng AI trong phát triển web
- Xây dựng quy trình riêng
- Ôn tập và bước tiếp theo

## Bảng gian lận tham khảo nhanh

### Mẫu prompt

**Tạo code:**
```
Tạo [component/hàm] [ngôn ngữ/framework] [mô tả].
Bao gồm: [yêu cầu]
Phong cách: [tiêu chuẩn coding]
```

**Gỡ lỗi:**
```
Tôi gặp [triệuứng] trong [ngữ cảnh].
Đây là lỗi: [thông báo lỗi]
Đây là code liên quan: [code]
Nguyên nhân và cách sửa?
```

**Review code:**
```
Kiểm tra code này về [vùng trọng tâm].
Kiểm tra: bảo mật, hiệu suất, best practices
Đề xuất cải thiện với giải thích.
```

**Học tập:**
```
Tôi là lập trình viên [mức] học [chủ đề].
Giải thích [khái niệm] so sánh với [khái niệm đã biết].
Cho ví dụ thực tế.
```

### Hướng dẫn chọn công cụ AI

| Task | Công cụ tốt nhất | Lý do |
|------|------------------|-------|
| Hoàn thành code nội dòng | GitHub Copilot | Nhanh, hiểu ngữ cảnh |
| Giải quyết vấn đề phức tạp | Claude | Suy luận sâu |
| Tạo component UI | v0.dev | Thiết kế sang code |
| Chỉnh sửa đa file | Cursor | Ngữ cảnh toàn dự án |
| Giải thích code | ChatGPT | Giải thích rõ ràng |
| Tạo test | CodiumAI | Tập trung test |

## Nguyên tắc chính cần nhớ

1. **AI là đối tác, không phải thay thế** — Bạn hướng dẫn, AI thực hiện
2. **Ngữ cảnh là vua** — Càng nhiều ngữ cảnh, đầu ra càng tốt
3. **Kiểm tra mọi thứ** — Luôn xác minh code AI tạo
4. **Lặp lại và tinh chỉnh** — Đừng chấp nhận đầu ra đầu tiên; nhờ cải thiện
5. **Học từ AI** — Dùng đầu ra AI để hiểu mẫu và best practices

Tạo bảng gian lận cá nhân:

3. Ghi công cụ AI tốt nhất cho mỗi task
4. Thêm mẫu hoặc template bạn thường dùng

## Điểm mấu chốt

Khóa học đã trang bị kỹ năng sử dụng AI hiệu quả trong mọi khía cạnh phát triển web. Bảng gian lận trên là tài liệu tham khảo nhanh — giữ nó bên cạnh khi tiếp tục xây dựng, học hỏi và phát triển với tư cách lập trình viên web được hỗ trợ AI.
