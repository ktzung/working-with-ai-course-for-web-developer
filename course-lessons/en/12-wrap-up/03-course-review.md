## Quick Reference Cheat Sheet

### Prompt Templates

**Code Generation:**
```
Create a [language/framework] [component/function] that [description].
Include: [requirements]
Style: [coding standards]
```

**Debugging:**
```
I'm experiencing [symptom] in [context].
Here's the error: [error message]
Here's the relevant code: [code]
What's the cause and fix?
```

**Code Review:**
```
Review this code for [focus areas].
Check: security, performance, best practices
Suggest improvements with explanations.
```

**Learning:**
```
I'm a [skill level] developer learning [topic].
Explain [concept] comparing it to [known concept].
Give me a practical example.
```

### AI Tool Selection Guide

| Task | Best Tool | Why |
|------|-----------|-----|
| Inline code completion | GitHub Copilot | Fast, context-aware |
| Complex problem solving | Claude | Deep reasoning |
| UI component generation | v0.dev | Design-to-code |
| Multi-file editing | Cursor | Project-wide context |
| Code explanation | ChatGPT | Clear explanations |
| Test generation | CodiumAI | Test-focused |

## Key Principles to Remember

1. **AI is a partner, not a replacement** — You guide, AI executes
2. **Context is king** — The more context you provide, the better the output
3. **Review everything** — Always verify AI-generated code
4. **Iterate and refine** — Don't accept the first output; ask for improvements
5. **Learn from AI** — Use AI outputs to understand patterns and best practices
